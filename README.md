# Poncheck Frontend

Point of Sale (POS) application for managing ponche businesses, including sales, inventory, cash registers, products, categories, users, and business operations. Built with Next.js and TypeScript, featuring role-based access control, responsive design, and support for multi-tenant business management.

## Tech Stack

### Frontend

* Next.js
* React
* TypeScript
* Tailwind CSS
* shadcn/ui
* TanStack Query
* Axios
* React Hook Form
* Zod
* Zustand

### Offline Support

* IndexedDB
* Dexie.js
* Service Workers
* PWA (Progressive Web App)

## Getting Started

Install dependencies:

```bash
pnpm install
```

Run the development server:

```bash
pnpm dev
```

Open:

```text
http://localhost:3000
```

## Features

* JWT Authentication
* Role-Based Access Control (Admin, Owner, Seller)
* Multi-Tenant Business Management
* User Management
* Product Management
* Category Management
* Inventory Tracking
* Inventory Movements History
* Sales Management
* Sales Cancellation Flow
* Cash Register Management
* Cash Movements Tracking
* Business Management
* Dashboard and Analytics
* Responsive Design
